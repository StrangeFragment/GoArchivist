# GoArchivist

Локальное приложение для архивации почты. Сейчас в проекте реализованы веб-интерфейс и системный трей; загрузка писем и вложений пока находится в разработке.

## Системный трей

- Обычный щелчок левой кнопкой по значку открывает веб-интерфейс в браузере по умолчанию.
- Контекстное меню значка содержит пункты **GoArchivist** (открыть интерфейс) и **Выход** (корректно остановить HTTP-сервер и закрыть программу).
- PNG для значка трея встроен в программу через `go:embed`.
- Для Windows EXE ICO добавлен в PE-ресурсы; сгенерированный `rsrc_windows_amd64.syso` автоматически подключается Go-линкером при сборке `windows/amd64`.

## Настройки IMAP

На странице настроек задаются IMAP-сервер, TLS-порт, имя пользователя, пароль и интервал проверки. Кнопка **Проверить соединение и сохранить** устанавливает TLS-соединение, проверяет авторизацию и получает каталог папок. Параметры подключения сохраняются только после успешной проверки и получения списка папок. В сообщении показывается только результат проверки, без перечня папок.

После подключения в отдельной секции настроек можно отметить папки для будущего наблюдения. При первом подключении по умолчанию включается только **Входящие (INBOX)**; остальные папки выключены. Каталог и выбор сохраняются в SQLite (`goarchivist.db`), а оригинальные IMAP-имена отделены от читаемых названий интерфейса. Повторное обновление каталога сохраняет выбор пользователя; новые папки автоматически не включаются.

Если пароль уже сохранён, поле можно оставить пустым, чтобы использовать прежний пароль. Пароль пока хранится в `config.json` в открытом виде; шифрование не входит в текущий этап.

Проверка подключения и выбор папок пока не запускают загрузку писем. В дальнейшем метаданные писем будут храниться в SQLite, а вложения — в файловой папке.

## Сборка Windows EXE

Файл `rsrc_windows_amd64.syso` уже включён в репозиторий. Поэтому для обычной сборки Windows/amd64 достаточно:

```powershell
$env:GOOS = "windows"
$env:GOARCH = "amd64"
go build -ldflags "-H=windowsgui" -o GoArchivist.exe .
```
