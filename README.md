# GoArchivist

Локальное приложение для архивации почты. Сейчас в проекте реализованы веб-интерфейс и системный трей; обработка почты и вложений пока находится в разработке.

## Системный трей

- Обычный щелчок левой кнопкой по значку открывает веб-интерфейс в браузере по умолчанию.
- Контекстное меню значка содержит пункты **GoArchivist** (открыть интерфейс) и **Выход** (корректно остановить HTTP-сервер и закрыть программу).
- PNG для значка трея встроен в программу через `go:embed`.
- Для Windows EXE ICO добавлен в PE-ресурсы; сгенерированный `rsrc_windows_amd64.syso` автоматически подключается Go-линкером при сборке `windows/amd64`.

## Сборка Windows EXE

В PowerShell из корня репозитория:

```powershell
.\scripts\build-windows.ps1
```

Скрипт генерирует ресурс Windows из `internal/app/assets/windows/goarchivist.ico` и собирает `dist/GoArchivist.exe` без консольного окна. Для генерации ресурса требуется доступ к модулю `github.com/akavel/rsrc@v0.10.2` при первом запуске.

Файл `rsrc_windows_amd64.syso` уже включён в репозиторий. Поэтому для обычной сборки Windows/amd64 достаточно:

```powershell
$env:GOOS = "windows"
$env:GOARCH = "amd64"
go build -ldflags "-H=windowsgui" -o dist/GoArchivist.exe .
```

## Запуск из исходников

```sh
go run .
```

По умолчанию веб-интерфейс доступен по адресу `http://127.0.0.1:8080`. Адрес можно изменить в пользовательском `config.json`.
