# GoArchivist

Локальное приложение для архивации почты. Сейчас в проекте реализованы веб-интерфейс и системный трей; обработка почты и вложений пока находится в разработке.

## Системный трей

- Обычный щелчок левой кнопкой по значку открывает веб-интерфейс в браузере по умолчанию.
- Контекстное меню значка содержит пункты **GoArchivist** (открыть интерфейс) и **Выход** (корректно остановить HTTP-сервер и закрыть программу).
- PNG для значка трея встроен в программу через `go:embed`.
- Для Windows EXE ICO добавлен в PE-ресурсы; сгенерированный `rsrc_windows_amd64.syso` автоматически подключается Go-линкером при сборке `windows/amd64`.

## Настройки IMAP

На странице настроек можно задать IMAP-сервер, TLS-порт, имя пользователя, пароль, папку и интервал опроса. Кнопка **Проверить соединение и сохранить** устанавливает TLS-соединение, проверяет авторизацию, получает список папок и сохраняет параметры только при успешной проверке и наличии выбранной папки. Если пароль уже сохранён, поле можно оставить пустым, чтобы использовать прежний пароль. Пароль пока хранится в `config.json` в открытом виде; шифрование запланировано отдельно.

Проверка подключения не запускает получение и архивацию писем: эти компоненты ещё не реализованы.

## Сборка Windows EXE

Файл `rsrc_windows_amd64.syso` уже включён в репозиторий. Поэтому для обычной сборки Windows/amd64 достаточно:

```powershell
$env:GOOS = "windows"
$env:GOARCH = "amd64"
go build -ldflags "-H=windowsgui" -o GoArchivist.exe .
```
